# Security policy

## Supported versions

Security fixes are applied to the latest release.

## Reporting a vulnerability

Please use GitHub's private vulnerability-reporting feature for this repository. Do not open a
public issue with exploit details, credentials, private data, or an unpatched proof of concept.

This project contains instruction and installer files, not a hosted service. Reports are still
welcome for unsafe installer behavior, path traversal, authority escalation, prompt-driven bypasses,
or release artifacts that differ from their reviewed source.
